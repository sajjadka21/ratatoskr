# Ratatoskr 1.0.2

The first public Windows and Android release. Download from the assets below or from [ratatoskr.hivenest.ir](https://ratatoskr.hivenest.ir).

## Downloads

- **Windows 10/11, x64:** `Ratatoskr_1.0.2_x64-setup.exe` is the recommended installer. `Ratatoskr_1.0.2_x64_en-US.msi` is the alternative MSI installer. Windows WebView2 is required.
- **Windows portable:** extract `Ratatoskr-portable.zip` into a writable folder and run `Ratatoskr.exe`. Preserve its `data` folder when replacing a portable installation.
- **Android 10 or later:** install `Ratatoskr-android.apk`. Share a supported video link with Ratatoskr, choose a quality, and follow progress in the notification. Android is a media-download companion; it does not include all desktop features.
- **Integrity:** `SHA256SUMS.txt` lists the SHA-256 hash of every attached asset. `latest.json` and the `.sig` file are for the Windows updater.

## Fixed

- Android 16 KB compatibility: yt-dlp/FFmpeg upgraded to 0.18.1; five nested WebP libraries rebuilt from official libwebp 1.6.0 source using Android NDK 27. The build checks SONAMEs, exported APIs and all 64-bit ELF load segments recursively.
- The cancelled 1.0.1 build was never published; its tag is preserved.

- Windows and Android assets are now collected from nested build folders and published together with checksums.
- Android public builds use a persistent production key. Releases fail if signing credentials are missing, and the APK certificate, identity and non-debuggable flag are checked before publication.
- Windows updater signatures are verified against the public key embedded in the app. App, installer, CLI and Android version numbers are checked together.
- Frontend tests/build, Rust checks/tests, Android unit tests and bot tests must pass before publication.

## Existing capabilities

- Persian and English on desktop, with right-to-left layouts and the Persian calendar.
- Segmented transfers, adaptive connections, retry/recovery, mirrors, queues, schedules and folder rules. Resume depends on server support and unchanged source content.
- Separate domestic/international traffic statistics using editable domain rules; these estimates are not an operator billing statement.
- Local database and backups, four visual themes, and the `tosk` command line controlling the same running desktop engine.
- Browser-extension files included with Windows. Store installation is not yet available; see the browser settings and [extension guide](https://github.com/sajjadka21/ratatoskr/tree/main/browser-extension).

## Notes

- Windows updater signing is present; Windows Authenticode signing is not. Windows may show an unknown-publisher warning.
- If you installed an experimental Android APK with the same package ID and a debug key, uninstall that experimental copy before installing this production-signed version. Save any app data you need first. Downloaded files in Downloads are separate from app data.
- Built artifacts and automated checks have been verified. Installation and real downloads on physical Windows/Android devices have not yet been independently verified.
- Media availability depends on the source website and network. Desktop FFmpeg is optional and needed for merging some separate video/audio formats; see Settings → Tools.
- Source is available under **PolyForm Noncommercial 1.0.0**. Personal/noncommercial use is allowed; commercial use requires a separate licence.

## فارسی

اولین انتشار عمومی Ratatoskr برای ویندوز و اندروید.

- **ویندوز ۱۰/۱۱، نسخهٔ ۶۴ بیتی:** نصب‌کنندهٔ EXE پیشنهاد می‌شود. MSI و نسخهٔ قابل‌حمل هم در فایل‌های همین انتشار هستند. برای به‌روزرسانی نسخهٔ قابل‌حمل، پوشهٔ data را حفظ کنید.
- **اندروید ۱۰ به بعد:** فایل APK را نصب کنید و لینک رسانهٔ پشتیبانی‌شده را با برنامه به اشتراک بگذارید. نسخهٔ اندروید فعلاً همراه دانلود رسانه است و همهٔ امکانات دسکتاپ را ندارد.
- کتابخانه‌های داخلی اندروید برای حافظهٔ ۱۶ کیلوبایتی بازسازی و به‌صورت خودکار بررسی شدند. نسخهٔ 1.0.1 پیش از انتشار متوقف شد.
- فایل SHA256SUMS.txt برای کنترل صحت دریافت فایل‌ها است. امضای به‌روزرسانی ویندوز و امضای ثابت اندروید بررسی می‌شود.
- نصب و دانلود روی دستگاه فیزیکی هنوز مستقلاً آزموده نشده است. ویندوز فعلاً گواهی ناشر Authenticode ندارد.
- اگر APK آزمایشی با کلید debug نصب کرده‌اید، پیش از نصب نسخهٔ رسمی باید آن نسخهٔ آزمایشی را پس از حفظ داده‌های لازم حذف کنید.
