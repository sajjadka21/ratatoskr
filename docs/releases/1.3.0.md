# Ratatoskr 1.3.0

Windows adds a compact Queue menu and a modal for queue settings and scheduling, accessible from the header, queue page and Settings. Closing or submitting Add link clears its text; previously consumed clipboard links are not inserted again automatically. Selecting a queue remains stable across refreshes. Fresh files keep their original names; colliding copies receive (1), (2), and subsequent suffixes before the extension, and the download list shows the actual saved filename.

Both platforms inspect accessible destination files separately from link history and present possible matches as informational hints. Existing files and partial downloads are not overwritten. Android includes persistent queue ordering, named queues, tap-to-resume/retry for eligible waiting/failed rows, one-row icon selection actions, live progress, a calendar preference, complete exit with paused work, and aggregated failure notifications with optional vibration. The centered gold Add button and Ratatoskr branding remain.

Windows was accepted by the owner during local testing. Android is published at the owner's request with further interface improvements planned; complete physical-device acceptance, all live Instagram cases and upgrade acceptance remain unverified. Production packages use the pinned Android signer and Windows updater key. Android 1.2.2 used a different signer and cannot upgrade directly; do not uninstall it without preserving local data. Local-test APKs have a separate package identity and are not production updates.

## فارسی

ویندوز: منوی جمع‌وجور صف و پاپ‌آپ تنظیمات و زمان‌بندی از هدر، صفحهٔ صف و تنظیمات در دسترس است. پس از بستن یا ثبت پنجرهٔ افزودن، لینک پاک می‌شود و کلیپ‌بورد قبلی دوباره خودکار وارد نمی‌شود. انتخاب صف با تازه‌شدن اطلاعات تغییر نمی‌کند. فایل اول بدون عدد و نسخه‌های تکراری با (1)، (2) و ادامهٔ شمارش ذخیره می‌شوند؛ نام فهرست با فایل واقعی هماهنگ است.

اندروید: صف و ترتیب پایدار، ساخت صف، لمس ردیف‌های مناسب برای ادامه/تلاش دوباره، ابزارهای انتخاب یک‌ردیفه، نوار پیشرفت لحظه‌ای، تقویم مطابق تنظیمات، خروج و توقف کارهای پس‌زمینه، و اعلان تجمیعی خطا با ویبرهٔ اختیاری. بررسی فایل‌های مشابه در مقصد از تاریخچه جداست و صرفاً اطلاع می‌دهد.
