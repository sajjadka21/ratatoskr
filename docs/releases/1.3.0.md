# Ratatoskr 1.3.0 preview

Android now has a compact plus button and a bottom dock for Downloads, History, Browser and Settings. File cards and settings use quieter surfaces and consistent typography. Adding links has one Download action: known file links go directly to HTTP, media pages keep quality selection, and unsupported generic links can fall back to guarded file transfer. HTML responses and authenticated media failures are not treated as files.

Windows file integrity/security and session events are collapsed by default; a checksum mismatch or security threat opens its checks. The details scrollbar is hidden while wheel, touch and keyboard scrolling remain available.

This preview keeps the original Android production signer, package name and data storage. Android version code is 10. Real-device upgrade and live media acceptance still remain pending. Android 1.2.2 installations have a different signer; uninstalling removes local data. Other previously published original-signer versions remain signing-compatible.

## فارسی

اندروید: نوار پایین برای دانلودها، تاریخچه، مرورگر و تنظیمات؛ دکمهٔ مثبت ساده؛ فهرست و تنظیمات خلوت‌تر. افزودن لینک فقط یک دکمهٔ «دانلود» دارد و انتخاب روش دانلود خودکار است. انتخاب کیفیت رسانه حفظ شده است.

ویندوز: بررسی سلامت فایل و رویدادها بازشونده‌اند. نوار اسکرول جزئیات مخفی شده، اما پیمایش همچنان کار می‌کند. هش نامطابق یا هشدار امنیتی، بخش بررسی را باز می‌کند.

این نسخه پیش‌انتشار است؛ نصب و دانلود واقعی روی گوشی هنوز باید تأیید شود. امضای اصلی اندروید حفظ شده است.
