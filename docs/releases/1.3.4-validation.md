## UI and usability

An isolated headless Chromium used fixture downloads and mocked native IPC; it never touched the user's open app, active downloads, clipboard, or browser profile. This validates rendering and interactions, not a replacement for native engine tests.

192 views covered Persian/English, dark/light, widths 960/1100/1280/1920 and heights 600/700/820/1080: download list, all settings tabs, queues, categories, statistics, Link collector, Add download, and link selection. Input included 100 downloads with long filenames and 150 pasted links with 100 history duplicates. No runtime errors, horizontal page overflow or unnamed visible buttons were found. Reopening Add with the same clipboard was checked in every scenario.

Verified fixes include correct direction for numeric filenames in Persian, keeping the selection editor open when background downloads complete, and explaining why a duplicated batch needs review before starting.

## Release scope and recovery

Windows and extension packages only. Existing Android and Telegram-bot working changes are excluded from the release commits. No database schema or user data migration changes were made. Keep 1.3.3 assets available; a faulty update can be withdrawn from latest without replacing immutable binaries.
