# Ratatoskr 1.2.3 preview

This patch restores the original Android production signing identity used by 1.0.2 and 1.1.1, after an accidental change of GitHub signing settings. The release pipeline pins the public certificate in source and rejects an unexpected configured signer before using the private key.

Android version code is 9. Existing installations with the original production signer should accept this APK as an update; physical installation/upgrade still needs acceptance. APK signatures, package identity and native-library alignment are verified before publication.

**If you installed the Android 1.2.2 preview:** that APK has a different signer and cannot update directly to this release. Keep it installed; do not uninstall it to bypass the error, because local queue/history may be lost. A data-preserving migration needs separate handling. Windows 1.2.2 is unaffected; this patch changes no desktop download behavior or updater key.

The appearance, Direct/Automatic explanations, visible failure/retry and download-integrity fixes from 1.2.2 remain included. This is a preview; stable automatic updates remain on the previously accepted stable release.

## فارسی

در این نسخه، امضای اصلی اندروید که نسخه‌های ۱.۰.۲ و ۱.۱.۱ با آن منتشر شده‌اند بازگردانده می‌شود. تغییر تنظیمات امضای GitHub اشتباهی بود. از این پس اثرانگشت عمومی گواهی در کد ثابت است و انتشار با کلید ناسازگار متوقف می‌شود.

کد نسخهٔ اندروید ۹ است. نصب‌های دارای امضای اصلی باید این فایل را به‌صورت آپدیت بپذیرند؛ نصب و ارتقا روی گوشی واقعی همچنان باید آزموده شود.

اگر پیش‌نمایش اندروید ۱.۲.۲ را نصب کرده‌اید، امضای آن متفاوت است و مستقیم به این نسخه آپدیت نمی‌شود. برنامه را برای دور زدن خطا حذف نکنید؛ صف و تاریخچه ممکن است پاک شود. مهاجرت بدون از دست رفتن داده‌ها باید جدا بررسی شود. ویندوز ۱.۲.۲ تحت تأثیر این مشکل نیست.
