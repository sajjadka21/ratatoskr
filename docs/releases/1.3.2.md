# Ratatoskr 1.3.2 — Windows

Ratatoskr now routes webpages to yt-dlp based on the server response, including pages from extractors outside the app's common-site hints. Direct media and ordinary file links continue through the native downloader. HTML responses are checked even when a server labels them as a binary download, avoiding accidental PHP, sign-in, or error-page files.

This uses the yt-dlp engine already bundled with or selected in Ratatoskr. The supported-sites list is broad, but each site can still impose sign-in, regional, age, rate-limit, or format restrictions; a site appearing in yt-dlp's list is not a guarantee that every link is downloadable. Some formats require FFmpeg for merging audio and video.

## فارسی

از این نسخه، صفحه‌های وب خارج از فهرست سایت‌های رایج برنامه هم از روی پاسخ سرور تشخیص داده می‌شوند و برای استخراج محتوا به yt-dlp می‌روند. لینک مستقیم فایل و ویدئو همچنان با دانلودر داخلی دریافت می‌شود. پاسخ‌های HTML حتی وقتی سرور آن‌ها را به‌اشتباه فایل باینری معرفی کند شناسایی می‌شوند تا صفحهٔ ورود، خطا یا فایل PHP به‌جای ویدئو ذخیره نشود.

این قابلیت از موتور yt-dlp همراه برنامه یا نسخه‌ای که در تنظیمات انتخاب شده استفاده می‌کند. فهرست سایت‌های yt-dlp گسترده است، اما ممکن است هر سایت به ورود، محدودیت منطقه‌ای، سن، تعداد درخواست یا فرمت خاصی نیاز داشته باشد؛ پشتیبانی یک نام در فهرست تضمین دانلود همهٔ لینک‌های آن سایت نیست. ادغام بعضی کیفیت‌های تصویر و صدا نیز به FFmpeg نیاز دارد.
