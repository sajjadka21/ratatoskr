## Windows in-app update repair

- Build updater installers with a compatible, pinned Tauri CLI so their signed trusted comment includes the application version required by installed clients.
- Verify both the cryptographic signature and its signed version before publishing. Reject missing or mismatched versions without disabling the installed application's safety checks.
- Keep the Windows 1.3.4 features and browser extension 1.2.3. Android is unchanged.

Updates from older installed versions can use this release's signed updater. If the error persists, retain the exact error text; network or installer failures are separate from the repaired signature mismatch.
