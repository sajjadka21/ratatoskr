## Clearer downloads list, and Persian and English polish

A release of interface improvements for Windows and Linux. Nothing changes in how files are downloaded.

### Easier to use

- **Finished downloads:** a row now has a *Show in folder* button, and double-clicking it opens the file.
- **Failed downloads say what to do next.** When the link has expired, was refused (401/403) or is missing (404), the row and the details panel offer *Refresh link* instead of a retry that would fail again. The reason now appears above the buttons, in your language.
- **Quit** has moved from the top bar to the bottom of the sidebar, next to Settings, where it is harder to press by accident. It is also in the command palette (Ctrl+K).
- **Persian file names** now read right to left, such as «گزارش سالانه ۱۴۰۵.pdf», in the list, the details panel, the queues page and the download window.

### Fixes

- The built-in queue is shown as «صف پیش‌فرض» in Persian and "Default queue" in English.
- Queue names on narrow rows are shown whole or not at all, never cut down to one letter; a status that does not fit ends with "…".
- In English, the icons in the top bar no longer shrink to a dot.
- Before the first bytes arrive, the speed shows "—" instead of a large Persian zero that looked like a bullet.
- English sentences about one item read correctly ("1 item", "1 completed download is…").
- On small windows the details panel opens above the top bar, so its close button is always visible, and the sidebar scrolls instead of squeezing the *Add link* button.
- *Send link to phone* sits below the everyday actions in the right-click menu, and its window no longer closes on its own.
- Queues page: clearer wording, a "No limit" hint for the per-site limit, and one highlighted button instead of two.
- Settings: schedule buttons read "Schedule for …", the Firefox button reads "Set up in Firefox", and the plugin guide opens with a button.
- Hints in the Link collector use the interface font, and in Persian they read right to left.
- Numbers in Persian (part counts, queue limits) use Persian digits.
- On Linux, the close dialog and first-run tips talk about the system tray, not "next to the clock".

Android and the browser extensions are unchanged (Android 1.3.2, extensions 1.2.3).
