## Windows link intake and YouTube

- Paste a linked title or a selected section of a webpage into Add download. The app reads the actual destinations, including multiple links, instead of just the visible labels.
- Reopening Add download imports the same clipboard again. Cancelling a dialog no longer makes that clipboard selection disappear on the next attempt.
- Recognize links attached to Persian text and Markdown labels.
- Include a verified Deno runtime for YouTube's JavaScript challenges. Prepare the checksum-verified FFmpeg helper automatically on the first video download when needed; existing user-selected tools are preserved.
- Download an entire YouTube playlist as separate downloads with one quality selection. A video link with a playlist now offers an explicit action to switch to the full playlist, and its individual entries can be reviewed before adding them.
- Keep playlist downloads blocked until their entries have loaded, so a failed lookup cannot silently download only the first video. Playlist discovery is limited to 500 entries per request.
- Retry a failed video lookup without retyping the link.
- Keep the link selection editor open while other downloads finish, display numeric filenames correctly in Persian, and hide the transient tool console during settings checks.
