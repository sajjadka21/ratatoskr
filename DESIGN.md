# Active design — Ratatoskr

The owner asked for a gentler light appearance, a different header, authentic app images, and copy derived from the real project.

The active direction uses warm paper (#E7E1D5), charcoal-green ink (#282C28), quiet brass (#79572F), and a forest primary action (#43513A). Dark mode uses #161B19 with warm light text. English uses Manrope; Persian uses Vazirmatn. Fonts remain self-hosted.

Header: an integrated horizontal navigation bar with the actual Tauri icon and exported app wordmark, plain text navigation, a GitHub link, language and appearance controls. Mobile uses a keyboard-accessible disclosure. No floating pill nav or white card header.

Hero: large two-line text, a meaningful download path, the actual app UI capture, a restrained world-tree line drawing and texture from the app's own assets. The frame settles on hover. Theme controls update both hero and gallery screenshots.

Content: real resume/segmented transfers (server-dependent), queues, schedules, folder rules, browser handoff and local backups. Windows and Android are differentiated. There are no fictional speeds, testimonials, user numbers, Linux/macOS downloads or release files.

Captures are the actual local React frontend running in a browser with no native Tauri backend. Empty download lists are intentionally preserved. They are explicitly labeled and do not imply installation or device testing.

Motion: 180–230ms feedback/menu/FAQ transitions, 320ms theme changes, one 650–750ms entrance, and a finite 1.5s tree-path draw. All respect reduced motion. No ornamental perpetual loops.

Keyboard navigation, visible focus, 44px main controls, persisted preferences, section anchor clearance and right-to-left layout are preserved. The landing remains vanilla HTML/CSS/JS.
