# Ratatoskr 1.3.0 preview

Android adopts the user-approved Ratatoskr design: a centered gold circular add button sits in a concave bottom navigation cradle between Downloads and Settings. Browser, search and menu actions are in the header. Active transfers use a prominent surface; waiting and completed files use compact grouped rows. Advanced link options stay collapsed behind More options. The interface retains attributed AB-derived components and existing preference controls.

Adding links has one Download action: known file links go directly to HTTP, media pages keep quality selection, and unsupported generic links can fall back to guarded file transfer. HTML responses and authenticated media failures are not treated as files. Ratatoskr's existing journal, queue, history, retry, clipboard, batch links, scheduling, network policies and media quality selection are retained. Light mode uses a warm, muted background; all four brand accents, dark/system appearance and Persian/English remain available.

Windows file integrity/security and session events are collapsed by default; a checksum mismatch or security threat opens its checks. The details scrollbar is hidden while wheel, touch and keyboard scrolling remain available.

This preview keeps the original Android production signer, package name and data storage. Android version code is 10. Real-device upgrade and live media acceptance still remain pending. Android 1.2.2 installations have a different signer; uninstalling removes local data. Other previously published original-signer versions remain signing-compatible.

## فارسی

اندروید از طرح تأییدشدهٔ Ratatoskr استفاده می‌کند: مثبت دایره‌ای طلایی در فرورفتگی وسط نوار پایین، بین دانلودها و تنظیمات قرار دارد. مرورگر، جست‌وجو و منو در هدر هستند. دانلودهای فعال برجسته و فایل‌های منتظر و تکمیل‌شده به‌صورت ردیف‌های گروه‌بندی‌شده نمایش داده می‌شوند. گزینه‌های پیشرفتهٔ افزودن لینک پشت گزینه‌های بیشتر قرار دارند. اجزای اقتباس‌شده از AB همراه اطلاعات مجوز حفظ شده‌اند.

فقط یک دکمهٔ «دانلود» وجود دارد و انتخاب روش دانلود خودکار است. صف، تاریخچه، ادامه، تلاش دوباره، زمان‌بندی، اشتراک‌گذاری، انتخاب کیفیت و سیاست Wi-Fi حفظ شده‌اند. تم روشن ملایم، تیره و هماهنگ با سیستم، چهار رنگ برند و فارسی و انگلیسی در دسترس‌اند.

ویندوز: بررسی سلامت فایل و رویدادها بازشونده‌اند. نوار اسکرول جزئیات مخفی شده، اما پیمایش همچنان کار می‌کند. هش نامطابق یا هشدار امنیتی، بخش بررسی را باز می‌کند.

این نسخه پیش‌انتشار است؛ نصب و دانلود واقعی روی گوشی هنوز باید تأیید شود. امضای اصلی اندروید حفظ شده است.
