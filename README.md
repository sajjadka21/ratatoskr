# Ratatoskr Landing Page

سایت معرفی دو زبانهٔ Ratatoskr، آمادهٔ انتشار با Cloudflare Workers Static Assets.

- فارسی: https://ratatoskr.hivenest.ir/fa/
- English: https://ratatoskr.hivenest.ir/
- آدرس پشتیبان: https://ratatoskr-site.sajjad-kazemi-edu.workers.dev/
- وضعیت فعلی محصول: در حال توسعه؛ هیچ دانلود، نسخه، آمار کاربر یا قابلیت تأییدنشده‌ای جعل نشده است.

## ساختار فایل‌ها

| مسیر | کاربرد |
|---|---|
| `src/index.html` | محتوای اصلی انگلیسی و ساختار صفحه |
| `scripts/fa.mjs` | ترجمهٔ فارسی، از جمله عنوان‌ها و توضیحات |
| `src/styles.css` | طراحی واکنش‌گرا، راست‌به‌چپ و ظاهر چهار تم |
| `src/app.js` | انتخاب تم، کنترل صفحه‌کلید و اتصال اطلاعات انتشار |
| `src/assets/` | تصاویر بهینه، لوگوهای SVG، آیکون‌ها و فونت محلی |
| `src/_headers` | سیاست امنیتی و کش |
| `site.config.json` | دامنه، مخزن GitHub و لینک‌های واقعی دانلود |
| `scripts/build.mjs` | خروجی فارسی/انگلیسی، sitemap، robots و صفحهٔ 404 |
| `dist/` | فایل‌های آمادهٔ انتشار؛ خروجی ساخت و قابل بازسازی |
| `wrangler.jsonc` | تنظیم اتصال Cloudflare و زیردامنه |
| `DEPLOYMENT.md` | وضعیت انتشار و نتیجهٔ بررسی‌ها |

## اجرای محلی

Node.js 22 یا جدیدتر مناسب است. از داخل این پوشه اجرا کنید:

```sh
npm ci
npm run build
npm run preview
```

پیش‌نمایش محلی در `http://127.0.0.1:4173` باز می‌شود. ساخت و پیش‌نمایش خود سایت وابستگی اجرایی خارجی ندارند؛ Wrangler فقط ابزار انتشار است.

## اضافه‌کردن اولین نسخهٔ اپ

بعد از آماده‌شدن اپ، فقط لینک‌های واقعی را در `site.config.json` وارد کنید:

- `repository`: نام مخزن عمومی به شکل `owner/repository`؛ تا زمان آماده‌شدن خالی بماند.
- `stage`: پس از انتشار به `released` تغییر دهید؛ نمایش دکمه‌ها بر اساس وجود فایل‌های واقعی است.
- `release.version`: شمارهٔ نسخهٔ واقعی.
- `release.publishedAt`: تاریخ ISO انتشار، مثلاً مقدار رسمی GitHub Release.
- `release.notesUrl`: آدرس HTTPS یادداشت‌های انتشار.
- `release.downloads`: فهرست فایل‌ها؛ هر مورد دارای `platform`، `label` و `url` است. مقادیر مجاز platform عبارت‌اند از `windows`، `macos` و `linux`.

برای معماری‌های متفاوت مثل ARM64 و x64، چند مورد با platform یکسان و label روشن اضافه کنید. سیستم‌عاملی که فایل ندارد همچنان وضعیت انتظار نشان می‌دهد. لینک‌ها باید HTTPS باشند.

پس از درج نام مخزن، `npm run sync-release` می‌تواند اطلاعات آخرین نسخهٔ پایدار عمومی GitHub را دریافت کند. این دستور فایل دانلود مناسب هر سیستم را حدس نمی‌زند؛ نگاشت فایل‌ها را صریح تنظیم کنید. سپس دوباره ساخت و انتشار را اجرا کنید.

قبل از معرفی نسخهٔ نهایی، متن امکانات، نیازمندی سیستم، تصاویر واقعی اپ و اطلاعات مجوز محصول را با خروجی نهایی برنامه تطبیق دهید. تصاویر فعلی پیش‌نمایش طراحی‌اند و در خود سایت نیز همین موضوع ذکر شده است.

## انتشار بعدی

```sh
npx wrangler login
npm run deploy
```

این دستور به حساب Cloudflare مالک دامنه دسترسی مجاز نیاز دارد. فایل ZIP هیچ کلید، توکن یا نشست ورود ندارد. انتشار نخست با پلاگین متصل Cloudflare و API رسمی انجام شده است؛ اتصال پلاگین لزوماً به معنی ورود ابزار محلی Wrangler نیست.

پروژه فقط فایل ثابت ارائه می‌دهد و کد سرور Worker، دیتابیس یا سرویس پولی ندارد. برای وضعیت فعلی، هاست Cloudflare Static Assets رایگان است؛ تغییرات آینده باید جداگانه از نظر هزینه بررسی شوند.

## دامنه و ایرنیک

دامنه در ایرنیک ثبت شده، اما DNS آن هم‌اکنون روی Cloudflare فعال است. nameserverهای فعلی `gabriella.ns.cloudflare.com` و `ram.ns.cloudflare.com` هستند. برای این زیردامنه نیاز به تغییر ایرنیک نیست. اتصال `ratatoskr.hivenest.ir` در Cloudflare به Worker `ratatoskr-site` انجام شده و HTTPS فعال است. nameserverها را عوض نکنید؛ پروژه‌های موجود، از جمله Parsyar، از همین DNS استفاده می‌کنند.

## تصاویر و مجوزها

تصاویر برند از بستهٔ Ratatoskr تأییدشده در همین گفتگو آمده‌اند و برای وب بهینه شده‌اند. پیش‌نمایش‌های UI سند امکانات نهایی نیستند. لوگو و تزئینات SVG، تصاویر WebP و فونت همگی از همین دامنه بارگیری می‌شوند. Vazirmatn تحت SIL Open Font License 1.1 است؛ متن مجوز در `src/assets/Vazirmatn-LICENSE.txt` همراه خروجی نگهداری می‌شود. این پروژه برای خود اپ یا برند، مجوز عمومی جدیدی تعیین نمی‌کند.

سایت ردیاب و فرم جمع‌آوری اطلاعات ندارد. فقط انتخاب تم در حافظهٔ مرورگر ذخیره می‌شود. فارسی مسیر مستقل `/fa/`، راست‌به‌چپ و فونت محلی دارد؛ زبان انگلیسی مسیر اصلی است. `canonical`، `hreflang` و تصویر اشتراک‌گذاری برای هر دو صفحه تنظیم شده‌اند.
