# Ratatoskr — بازبینی محصول، ویندوز و اندروید

تاریخ: ۲ اکتبر ۲۰۲۶. مبنا: تغییرات Claude در main و PR 26، به‌همراه اصلاحات PR 27. این گزارش بین بررسی کد، آزمون خودکار و تجربه روی دستگاه واقعی تفاوت می‌گذارد. هیچ آزمون خودکاری به‌تنهایی تأیید تمام گوشی‌ها، تمام سرورها یا تمام لینک‌های اینستاگرام نیست.

## نتیجهٔ بررسی

نسخهٔ جدید قابلیت‌های مهمی دارد، اما برای عرضهٔ نهایی صرفاً اضافه کردن قابلیت کافی نیست. بازبینی، اشکالات قابل بازسازی در تغییر ظاهر، صحت فایل، بازیابی و نمایش خطا را پیدا کرد. این‌ها پیش از تبلیغ سرعت یا انتشار پایدار اولویت دارند. تغییرات Claude حفظ شده‌اند؛ اصلاحات روی همان پیاده‌سازی انجام می‌شوند.

## «Checking link» و «Direct» دقیقاً چه هستند؟

Automatic ابتدا نوع لینک را مشخص می‌کند. برای صفحهٔ ویدیو، اطلاعات رسانه، کیفیت‌ها و گاهی موارد یک پست یا آلبوم استخراج می‌شوند. این مرحله هنوز دانلود نهایی فایل انتخاب‌شده نیست و برای سایت‌های رسانه‌ای ممکن است به پاسخ سایت و موتور استخراج وابسته باشد. توضیح فارسی/انگلیسی و امکان لغو به صفحه اضافه شده است.

Direct برای URL خود فایل است؛ مانند ZIP، PDF یا MP4. برای صفحهٔ پست اینستاگرام، صفحهٔ پخش ویدیو یا آدرس ورود، گزینهٔ مناسب Automatic است. حتی یک لینک مستقیم ممکن است منقضی، محدود به ورود یا از طرف سرور مسدود شود. خطای واقعی باید دیده شود؛ سکوت یا ناپدید شدن کار قابل قبول نیست.

## مسیرهای بررسی‌شدهٔ اندروید

* افزودن تکی، چندتایی و الگوی عددی؛ استخراج لینک از متن؛ Share، clipboard، Open with و tile.
* تفکیک فایل و رسانه، انتخاب کیفیت/صدا/آلبوم، دانلود عمومی اینستاگرام و محدودیت محتوای خصوصی.
* ذخیرهٔ پایدار صف و تاریخچه، توقف/ادامه، recovery، retry، تشخیص هویت فایل و range fallback.
* Wi-Fi، محدودیت سرعت، تعداد اتصال، زمان شروع و پنجرهٔ زمانی، JobScheduler و foreground service.
* پوشهٔ عمومی و انتخاب پوشه با SAF، نام ایمن، فضای خالی، checksum و باز کردن/اشتراک فایل.
* Active/History، جست‌وجو، دسته‌بندی، انتخاب چندتایی و اقدامات گروهی.
* چهار تم، روشن/تیره/سیستم، فارسی RTL و انگلیسی، دسترس‌پذیری و حفظ تنظیمات.
* مرورگر داخلی، pluginهای declarative، refresh link، درباره/diagnostics و به‌روزرسانی با رضایت کاربر.

وجود کد و آزمون برای این مسیرها به معنی عبور آزمون end-to-end روی گوشی کاربر نیست. به‌خصوص Doze، kill توسط سازنده، تغییر شبکه، SAF ارائه‌دهنده‌های مختلف و نصب آپدیت باید روی دستگاه واقعی نیز بررسی شوند.

## مسیرهای بررسی‌شدهٔ ویندوز

* موتور Rust، Range و resume، انتقال هم‌زمان، retry، زمان‌بندی، quota، checksum و کنترل فضای دیسک.
* دریافت لینک از clipboard ساده و HTML/انتخاب مرورگر، افزونه، native host، CLI و drop box.
* جدول و جزئیات دانلود، دسته‌بندی، صف، جست‌وجو، انتخاب گروهی، میان‌برها و command palette.
* تم و زبان، بستن به tray، پنجرهٔ کوچک، وضعیت خطا، به‌روزرسانی امضاشده و backup.
* ساخت x64 و بررسی سازگاری کامپایل ARM؛ کامپایل ARM به معنی تحویل installer ARM نیست.

نصب/حذف واقعی NSIS و MSI، نمایش picker فارسی، SmartScreen، Explorer integration و ارتقا با دیتابیس قدیمی، پذیرش مستقل روی ویندوز نصب‌شده نیاز دارند.

## مقایسهٔ قابل اتکا با رقبا

چند اتصال، ادامهٔ دانلود، زمان‌بندی و اتصال مرورگر ویژگی منحصربه‌فرد نیستند: [IDM](https://www.internetdownloadmanager.com/support/options.html) و [FDM](https://www.freedownloadmanager.org/features.htm) آن‌ها را عرضه می‌کنند. [زمان‌بندی IDM](https://www.internetdownloadmanager.com/support/idm-scheduler/idm_scheduler.html) و [دریافت لینک‌های انتخاب‌شده](https://www.internetdownloadmanager.com/support/right_click_IE.html) معیارهای مفیدی برای رفتار کاربرپسند هستند. [1DM](https://play.google.com/store/apps/details?id=idm.internet.download.manager) روی اندروید مرورگر داخلی و امکانات گستردهٔ مدیریت دانلود دارد. بدون اندازه‌گیری نمی‌توان ادعای «سریع‌تر از همه» یا «۱۰ برابر» کرد.

| حوزه | جایگاه Ratatoskr | پیشنهاد |
|---|---|---|
| فایل مستقیم و resume | امکانات اصلی موجود؛ صحت خروجی معیار رقابت است | نمایش توضیح resume و خطای سرور؛ تست فایل‌های بزرگ و سرورهای مختلف |
| فارسی/انگلیسی و ظاهر | چهار هویت هماهنگ و RTL مزیت قابل نمایش برای مخاطب فارسی است | اسکرین‌شات واقعی، متن کوتاه، کنترل‌های قابل لمس؛ پرهیز از شلوغی |
| رسانهٔ عمومی | Share موبایل و انتخاب کیفیت مسیر مهمی است | نصب موتور و نتیجه/محدودیت لینک روشن باشد؛ private/login وعده داده نشود |
| ارتباط موبایل/ویندوز | انتقال لینک با QR و بدون حساب کاربری مسیر جذابی است | اتصال و تأیید مقصد ساده؛ آزمون واقعی روی دو دستگاه |
| نصب افزونه | ZIP دستی برای عرضهٔ عمومی اصطکاک دارد | انتشار رسمی در Chrome/Edge/Firefox store اولویت بالایی دارد |
| پایداری موبایل | صف پایدار و policies پایه موجود است | آزمون OEM kill، reboot، Wi-Fi قطع/وصل و Android 15 dataSync timeout |
| تنظیمات پیشرفته | ویندوز از موبایل کامل‌تر است | backup/restore موبایل، صف/اولویت و mirrors پس از تثبیت هسته |
| torrent/FTP | خارج از دامنهٔ فعلی | به‌جای وعدهٔ ناتمام، روی فایل HTTP و رسانهٔ عمومی تمرکز شود |

## اینستاگرام روی گوشی

مسیر پیشنهادی: Instagram → Share/Copy link → Ratatoskr → Automatic → انتخاب رسانه → ذخیره. صفحهٔ عمومی باید از صفحهٔ خصوصی یا نیازمند ورود تفکیک شود. لینک مستقیم CDN ممکن است عمر کوتاه داشته باشد. مرورگر داخلی جایگزین تضمین‌شده‌ای برای استخراج همهٔ پست‌ها نیست. خروجی Spotify نیز فایل اصلی Spotify نیست؛ metadata برای یافتن صوت متناظر استفاده می‌شود و باید شفاف معرفی شود.

برای پذیرش واقعی، یک Reel عمومی، پست تک‌عکس و آلبوم عمومی با شبکهٔ گوشی آزمایش می‌شوند. برای محتوای در دسترس نبودنی، پیام روشن و امکان باز کردن منبع لازم است. ذخیره یا درخواست رمز/کوکی حساب با قواعد پروژه سازگار نیست.

## قبل از انتشار پایدار

1. عبور آزمون‌های خودکار روی همان commit نهایی، بررسی تصاویر رابط و اعتبارسنجی همهٔ فایل‌های release.
2. گوشی واقعی: share اینستاگرام، فایل بزرگ، pause/resume، بستن برنامه، خاموش/روشن، Wi-Fi only، تغییر تم/زبان حین کار، SAF و نصب آپدیت.
3. ویندوز واقعی: نصب تازه، ارتقا از نسخهٔ قبلی، portable، افزونه، tray، لینک منتخب و کار با صفحه‌کلید.
4. انتشار افزونه‌ها در فروشگاه و تصمیم مالک دربارهٔ گواهی Authenticode؛ امضای updater با گواهی رفع SmartScreen یکی نیست.
5. تبلیغات و سایت فقط قابلیت و نسخهٔ واقعاً موجود را معرفی کنند. تا پذیرش دستگاه، خروجی جدید preview/prerelease می‌ماند.

## محدودیت محیط بررسی

گوشی یا شبیه‌ساز محلی متصل نیست. آزمون رابط بومی با شبیه‌سازهای Android API 26، 29 و 35 در CI اجرا می‌شود. این تصاویر واقعی اجرای برنامه هستند، اما گوشی کاربر و لینک شکست‌خوردهٔ او را بازسازی نمی‌کنند. برای مرحلهٔ دستگاه واقعی، اتصال USB با USB debugging و تأیید رایانه کافی است؛ رمز یا اطلاعات حساب لازم نیست.
