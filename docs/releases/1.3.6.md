## Ratatoskr for Linux, and Windows fixes

### New: Linux

Ratatoskr now runs on Linux, on any 64-bit distribution with WebKitGTK 4.1 (Debian 12+, Ubuntu 22.04+, Mint 21+, Fedora 37+, openSUSE, Arch, Manjaro and their derivatives). Choose one:

| File | For |
|---|---|
| `Ratatoskr_1.3.6_amd64.deb` | Debian, Ubuntu, Linux Mint, Pop!_OS, elementary, Zorin: `sudo apt install ./Ratatoskr_1.3.6_amd64.deb` |
| `Ratatoskr-1.3.6-1.x86_64.rpm` | Fedora, openSUSE, RHEL/Alma/Rocky: `sudo dnf install ./Ratatoskr-1.3.6-1.x86_64.rpm` or `sudo zypper install ./Ratatoskr-1.3.6-1.x86_64.rpm` |
| `Ratatoskr-1.3.6-linux-x86_64.tar.gz` | Any distribution, no package manager or AppImage needed: unpack, then run `./install.sh` (menu entry for you only) or `./bin/ratatoskr` |
| `Ratatoskr_1.3.6_amd64.AppImage` | Any distribution, single file: `chmod +x` and run |

The .deb, .rpm and AppImage update from inside the app, signed like the Windows installer. The archive announces new versions and is replaced by hand; downloads and settings are kept in `~/.local/share/com.downloadmanager.desktop`.

On Linux the browser connector registers itself for Chrome, Chromium, Brave, Edge and Firefox profiles; downloads that need the browser's login are handed over through a socket only your user can reach, and only to the installed program. Start-at-sign-in, sleep/hibernate/shut down after downloads, keeping the computer awake, free-space checks and finish sounds use the desktop's own facilities. yt-dlp and its JavaScript runtime ship with the packages; install `ffmpeg` from your distribution to join video and sound downloaded separately.

### Fixes (Windows and Linux)

- A failed download's reason is no longer pushed out of sight by the queue name on narrower windows.
- If one view fails to draw, Ratatoskr shows a way back to the download list instead of an empty window. Downloads keep running in the background.
- The portable Windows copy no longer offers to run the installer, which added a second installed copy instead of updating the portable folder. It now announces the new version and opens the download page.

Android and the browser extensions are unchanged (Android 1.3.2, extensions 1.2.3).
