# Ratatoskr 1.1.1 — rich clipboard preview

Includes the [1.1.0 reliability preview](https://github.com/sajjadka21/ratatoskr/releases/tag/v1.1.0), plus copied webpage selection support on Windows.

## Copied selections

Select a webpage region containing download labels, press **Ctrl+C**, then open Ratatoskr's **Add download** with clipboard input enabled. The app now reads the selected HTML link destinations as well as plain text. You can copy labels such as “Part 1 / Part 2” without copying each link address separately.

- Preserves link order and removes duplicates.
- Resolves relative links from CF_HTML's source page and decodes HTML entities once, preserving signed query bytes.
- Recognizes a link even when only its label was selected and its opening anchor is in the clipboard context.
- Ignores unselected neighbors, scripts, embedded image/frame sources, non-web schemes and credential fields.
- Clipboard contents remain transient; markup is never executed or rendered.
- Automatic clipboard watching uses the same extraction path, while continuing to offer only recognized download/media links.

If a page exposes a download only through JavaScript without a real hyperlink, selection-copy alone cannot supply that file URL. This change requires copying the selected region; it does not read an uncopied browser selection.

Windows updater signatures, persistent Android production signing, all architecture APKs, corresponding Android source and browser ZIPs follow the previous preview's release checks. This release remains a **prerelease** pending the physical-device gates in `docs/mobile-acceptance.md`. Authenticode and extension-store approvals remain unavailable.

## فارسی

بخشی از صفحه که عنوان لینک‌ها داخل آن است انتخاب کن، **Ctrl+C** بزن و پنجرهٔ **افزودن دانلود** را با ورودی کلیپ‌بورد باز کن. برنامه حالا آدرس پشت عنوان‌هایی مثل «بخش ۱ / بخش ۲» را از HTML کپی‌شده تشخیص می‌دهد؛ لازم نیست آدرس تک‌تک لینک‌ها را جدا کپی کنی.

ترتیب لینک‌ها حفظ می‌شود، تکراری‌ها حذف می‌شوند و لینک نسبی و نام فارسی پشتیبانی می‌شوند. لینک‌های بیرون بخش انتخاب‌شده وارد نمی‌شوند. HTML اجرا نمی‌شود و محتوای کلیپ‌بورد ذخیره یا ثبت نمی‌شود.

اگر دکمهٔ دانلود فقط با JavaScript ساخته شده و لینک واقعی ندارد، انتخاب و کپی به‌تنهایی آدرس فایل را فراهم نمی‌کند. این نسخه تمام قابلیت‌های پیش‌انتشار ۱.۱.۰ را هم دارد و تا تأیید آزمون روی دستگاه‌ها، جای نسخهٔ پایدار در به‌روزرسان خودکار قرار نمی‌گیرد.
