## Windows image downloads

- Choosing “Download with Ratatoskr” for an image now opens the app's normal download dialog instead of a separate browser tab.
- Choose the original image or save a PNG, JPEG, or WebP copy. The original stays in place; a numbered filename is used when a converted copy already exists.

This release updates Windows and browser extensions. Android remains on 1.3.2.
