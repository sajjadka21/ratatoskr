# Ratatoskr Landing Page

سایت دو زبانهٔ Ratatoskr / راتاتوسک، متصل به پروژهٔ واقعی `sajjadka21/ratatoskr`.

- فارسی: https://ratatoskr.hivenest.ir/fa/
- English: https://ratatoskr.hivenest.ir/
- انتشار: Cloudflare Workers Static Assets، Worker `ratatoskr-site`.
- وضعیت اپ در زمان بررسی: ساخت Windows و Android در CI موفق، انتشار عمومی هنوز انجام نشده.

## طراحی فعلی

حالت روشن زمینهٔ ماسه‌ای `#E7E1D5` دارد و حالت تاریک سبز زغالی `#161B19`. هدر ساده با لوگوی واقعی O درختی، ناوبری متنی، GitHub، تغییر زبان و ظاهر است. انتخاب چهار تم اپ از ظاهر خود سایت مستقل است و تصویر هیرو و گالری را هم‌زمان تغییر می‌دهد. منوی موبایل با Escape بسته می‌شود. انیمیشن ورود، تغییر تم و رسم نشان درختی با تنظیم کاهش حرکت غیرفعال می‌شوند.

## تصاویر و منابع

منبع برند و متن امکانات، کد محلی `D:/project/download-manager` است. فایل‌های `src/assets/screen-*.jpg` اسکرین‌شات رابط واقعی React در مرورگر با فهرست خالی‌اند: چهار تم و صفحهٔ تنظیمات. هیچ سرعت، دانلود یا شمارندهٔ ساختگی اضافه نشده. آن‌ها تصویر نسخهٔ نصب‌شدهٔ Windows یا گوشی Android نیستند؛ این موضوع در سایت هم توضیح داده شده. مشخصات و checksum تصاویر در `APP_REFERENCE.json` است.

- `app-icon.png`، favicon و apple-touch-icon: آیکون واقعی Tauri پروژه.
- `wordmark-app.svg`: استخراج از `src/brand/Wordmark.tsx`، دارای O درختی.
- `icon-*.webp` و `pattern-*.webp`: تصاویر خود اپ.
- `app-theme-reference.json`: رنگ‌های دقیق از `src/styles/brand-themes.css`.
- فونت‌های Manrope / Vazirmatn محلی بارگیری می‌شوند و مجوزشان همراه assets است.
- SVGهای قبلی Ant Design و مجوز MIT آن‌ها در بسته حفظ شده‌اند.

## اجرای محلی

Node.js 22 یا جدیدتر:

```sh
npm ci
npm run build
npm run preview
```

پیش‌نمایش در `http://127.0.0.1:4173` است. سایت برای اجرا به React یا سرویس خارجی نیاز ندارد.

## اضافه کردن ریلیز واقعی

بعد از منتشرشدن ریلیز، `site.config.json` را با شمارهٔ نسخه، تاریخ ISO، لینک یادداشت‌ها و فایل‌های HTTPS واقعی به‌روز کنید. `release.downloads` از platformهای `windows` و `android` پشتیبانی می‌کند؛ هر ورودی شامل `platform`، `label` و `url` است. هر نسخه فقط زمانی دکمهٔ دریافت می‌گیرد که فایل واقعی برایش تنظیم شده باشد. `npm run sync-release` فقط متادیتای آخرین ریلیز پایدار را می‌گیرد و فایل‌های دانلود را برای انتخاب صریح فهرست می‌کند.

پس از انتشار، متن‌های مربوط به انتظار ریلیز در FAQ و بخش دریافت را هم با وضعیت جدید هماهنگ کنید؛ موفقیت CI به‌تنهایی مجوز نمایش «قابل دانلود» نیست.

## دامنه

زیردامنه به Worker متصل است و HTTPS دارد. nameserverهای فعلی hivenest.ir را تغییر ندهید؛ پروژه‌های موجود از جمله Parsyar از همین DNS استفاده می‌کنند.

سایت فرم دریافت اطلاعات، ردیاب یا analytics ندارد؛ فقط انتخاب ظاهر و تم در مرورگر ذخیره می‌شود. این بسته مجوز عمومی جدیدی برای خود اپ یا برند تعیین نمی‌کند.
