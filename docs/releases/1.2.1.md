# Ratatoskr 1.2.1

## Android

- **Faster downloads:** a file is split over up to 8 connections (Settings), resumes after a break, and a connection that finishes early takes half of the slowest remaining part.
- **Add many links at once:** paste any text, or an address like `photo[01-20].jpg`; files and videos go to the right engine. A copied link is offered when the app opens.
- **Spotify tracks** are saved as audio found on YouTube (Spotify's own streams are DRM-protected).
- **New home screen and Settings page:** cards with size, speed and time left, Active/History tabs, details sheet, one Settings page that saves as you change it.
- **Scheduling:** start a download at a date and time, or only download between set hours (it may pass midnight).
- **Updates:** checks once a day (switchable), asks before downloading, verifies the published SHA-256, then Android confirms the install.
- **Small things:** category filter chips, automatic retry after a dropped connection (3 times), a sound when a download finishes, and "Open with Ratatoskr" for file links.
- **Android 8 and later** (was Android 10). One APK per CPU instead of a universal APK; `Ratatoskr-android.apk` is the arm64 build.

## Desktop

- **Part info** in the download window: one block per connection filling as it arrives, a per-part table, and "Resume support".
- **Exact schedules:** one-time date and time (with an optional stop) for a queue, and "Schedule this download" in the right-click menu.
- **Update prompt:** a new version asks "Update now / Later / Skip this version" before anything is downloaded.
- Smaller program (`opt-level = "s"`).

## Both

- **Plugins:** small JSON rule files (rewrite a link, rename a file, per-site Referer/User-Agent on desktop). Data only, never code. See [docs/PLUGINS.md](../PLUGINS.md).

Windows 10 or later is required; Windows 7 and 8.1 cannot be supported. This release stays a **prerelease** until the physical-device checks in `docs/mobile-acceptance.md` pass.

## فارسی

- **اندروید:** دانلود چنداتصاله با ادامه‌ی خودکار، افزودن چند لینک با هم و الگوی `file[01-20].jpg`، پیشنهاد دانلود لینک کپی‌شده، آهنگ اسپاتیفای (صدای هم‌نام از یوتیوب)، صفحه‌ی اصلی و تنظیمات جدید، زمان‌بندی شروع و بازه‌ی زمانی مجاز، به‌روزرسانی با اجازه و بررسی SHA-256، پشتیبانی از اندروید ۸ به بالا، و APK جدا برای هر CPU.
- **دسکتاپ:** پنجره‌ی «اطلاعات قطعه‌ها»، زمان‌بندی یک‌باره با تاریخ و ساعت، زمان‌بندی تک‌دانلود از منوی راست‌کلیک، و پرسیدن قبل از به‌روزرسانی.
- **هر دو:** افزونه‌های JSON (فقط داده، بدون اجرای کد).

## Reliability fixes included in this preview

- Android appearance changes remain usable without leaving Settings; preserve scroll, home tab and search.
- Failed tasks remain visible with a clear explanation and Retry. Automatic inspects media pages; Direct accepts actual file URLs.
- Clean single-stream fallback when a server ignores Range or changes validators; reject corrupt segment journals.
- Isolate payload filenames from transfer metadata and reuse files already published before interruption.
- Improve Android touch targets, control labels, category icons and selection actions.
- Windows preserves the latest theme choice and restores keyboard focus when its close dialog is cancelled.
- Automated coverage includes 244 Android unit tests, 193 frontend tests, Rust workspace checks and native emulator smoke tests on Android 8, 10 and 15.
