Before you start

A few things to know.

Can I download it now?+

Not yet. Both platform builds passed, but the publishing workflow stopped before creating the GitHub release. This page links only to published download files.

Which Linux file should I choose?+

On Debian, Ubuntu or Mint choose the .deb; on Fedora or openSUSE, the .rpm. Both update from inside the app. The AppImage is a single file that runs on any distribution. The .tar.gz archive needs no package manager: unpack it and run ./install.sh. Install ffmpeg from your distribution to join video and sound that are downloaded separately.

Is the Android app the same as Windows?+

Both apps manage downloads and named queues. The desktop app for Windows and Linux adds browser integration, a command line and detailed queue scheduling. Android adds sharing from other apps, network preferences and grouped failure notifications with optional vibration.

Do I need an account?+

No mandatory account is required for the local download manager. Download history and settings are kept on your device.

Is it free to use?+

Desktop is free for personal and noncommercial use under PolyForm Noncommercial 1.0.0; commercial use requires a separate licence. Android is GPL-3.0, including commercial use under its terms. Sources are available on GitHub.

Are these real screenshots?+

Yes. The hero combines the current Windows interface rendered in a browser with a native Android 1.3.0 emulator capture. Older desktop theme samples are shown separately. Screenshots do not replace physical-device testing.
