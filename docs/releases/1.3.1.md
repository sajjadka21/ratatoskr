# Ratatoskr 1.3.1 — Windows

Windows now saves categorized downloads under the system Downloads folder. Applications, archives, documents, videos, audio, images and other files each get their own subfolder. Missing folders are created automatically when the download starts. An explicitly configured rule, category or per-download destination still takes precedence.

This is a Windows-only update. Android remains on version 1.3.0.

## فارسی

دانلودهای دسته‌بندی‌شدهٔ ویندوز حالا در پوشهٔ استاندارد Downloads ذخیره می‌شوند و برای برنامه‌ها، آرشیوها، اسناد، ویدیوها، صدا، تصاویر و سایر فایل‌ها زیرپوشهٔ جدا دارند. اگر پوشه‌ای وجود نداشته باشد، هنگام شروع دانلود ساخته می‌شود. مسیر صریحی که برای قانون، دسته یا دانلود مشخص شده باشد همچنان اولویت دارد.

این به‌روزرسانی فقط برای ویندوز است؛ نسخهٔ اندروید روی ۱.۳.۰ می‌ماند.
