# Ratatoskr landing page

سایت معرفی دوزبانهٔ Ratatoskr با تصاویر رابط واقعی پروژه، حالت روشن ملایم و حالت تاریک.

- فارسی: https://ratatoskr.hivenest.ir/fa/
- English: https://ratatoskr.hivenest.ir/
- انتشار فعلی از GitHub Releases خوانده می‌شود؛ شمارهٔ ویندوز و اندروید مستقل به‌روز می‌شوند.
- میزبانی: Cloudflare Workers Static Assets، Worker موجود ratatoskr-site.

## محتوا و تصاویر

Wordmark با O درختی، آیکون برنامه، چهار آیکون/پترن و رنگ‌های تم از پروژهٔ دانلود منیجر گرفته شده‌اند. تصاویر دسکتاپ (hero-1.3.7، screen-*، sample-*) رابط واقعی نسخهٔ ۱.۳.۷ هستند که در مرورگر با دانلودهای نمونه اجرا شده‌اند، برای هر زبان جداگانه (-en و -fa)؛ متن صفحه هم نمونه‌بودن فایل‌ها را می‌گوید. تصاویر اندروید از نسخهٔ ۱.۳.۰ در شبیه‌ساز هستند.

فونت‌های Manrope و Vazirmatn خودمیزبان هستند. آیکون‌های عمومی از مجموعهٔ Ant Design با مجوز MIT انتخاب شده‌اند؛ مجوز فونت‌ها و آیکون‌ها همراه assets است.

محتوا روی قابلیت‌های موجود تمرکز دارد: فارسی/تقویم شمسی، ترافیک داخلی و بین‌المللی، موتور مشترک GUI/CLI و ذخیره‌سازی محلی. تفاوت امکانات و مجوز اندروید و دسکتاپ در FAQ روشن شده است.

## فایل‌های اصلی

| مسیر | کاربرد |
|---|---|
| src/index.html | ساختار و متن انگلیسی |
| scripts/fa.mjs | ترجمهٔ فارسی |
| src/styles.css و src/header.css | چیدمان، هدر، دو حالت رنگ و نمایش موبایل |
| src/app.js | منو، تغییر حالت رنگ و پیش‌نمایش تم‌ها |
| site.config.json | دامنه و لینک‌های واقعی انتشار |
| scripts/release-content.mjs | درج لینک‌های دانلود در HTML هر دو زبان؛ دانلود به JavaScript وابسته نیست |
| scripts/sync-release.mjs | واردکردن انتشارهای stable برای ساخت ایستا و بررسی checksumها |
| worker.mjs | تازه‌کردن خودکار نسخه و لینک‌ها از GitHub Releases؛ cache پنج‌دقیقه‌ای |
| scripts/build.mjs | ساخت صفحات فارسی/انگلیسی، SEO، sitemap و صفحهٔ 404 |
| dist/ | خروجی آمادهٔ انتشار |
| DEPLOYMENT.md | اطلاعات انتشار Cloudflare |
| docs/RELEASE_AUDIT.md | گزارش انتشار برنامه و حدود بررسی |
| docs/release-workflow.yml | روند انتشار واقعی و اعمال‌شده در مخزن برنامه |

## اجرای محلی

این سایت از ۲۰۲۶-۱۰-۲۹ در پوشهٔ `website/` مخزن اصلی Ratatoskr است و تاریخچهٔ git آن هم منتقل شده است. همهٔ دستورها را داخل `website/` اجرا کن. CI مخزن، سایت را می‌سازد و تست Worker را اجرا می‌کند.

Node.js 22 یا جدیدتر:

```sh
npm ci
npm run build
npm run preview
```

پیش‌نمایش روی http://127.0.0.1:4173 اجرا می‌شود.

## انتشار نسخهٔ بعدی

برای ساخت ایستای محلی یا بازبینی محتوا، بعد از انتشار موفق فایل‌ها در GitHub:

```sh
npm run sync-release
npm run build
npm run deploy
```

Worker فعال، آخرین انتشار stable کامل ویندوز و آخرین انتشار کامل اندروید را مستقیم از GitHub می‌خواند؛ بنابراین پس از انتشار برنامه، دکمه‌های دانلود و شماره نسخه سایت حداکثر پس از پنج دقیقه به‌روز می‌شوند و انتشار دوبارهٔ سایت لازم نیست. اندروید می‌تواند روی نسخهٔ قبلی بماند.

همگام‌سازی ایستا برای بازسازی صفحات لوکال، تاریخ، لینک‌ها و checksumها را از انتشارهای واقعی می‌گیرد و اگر فایل یا checksum لازم نباشد متوقف می‌شود. تغییرات محتوایی یا تصویری سایت همچنان نیازمند ساخت و انتشار سایت هستند.

برای deploy با Wrangler به حساب Cloudflare صاحب همین Worker وارد شوید. هیچ توکن، کلید امضا یا رمز عبوری در این بسته قرار ندارد. HTTPS و زیردامنه فعال‌اند؛ تغییر دیگری در IRNIC لازم نیست.
