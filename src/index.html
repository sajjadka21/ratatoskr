Before you start

A few things to know.

Can I download it now?+

Not yet. Both platform builds passed, but the publishing workflow stopped before creating the GitHub release. This page links only to published download files.

Is the Android app the same as Windows?+

The Android companion focuses on shared and pasted media links, quality selection and background downloads. The Windows app includes broader file management, queues and scheduling.

Do I need an account?+

No mandatory account is required for the local download manager. Download history and settings are kept on your device.

Are these real screenshots?+

Yes: they are captures of the actual interface from the local source, rendered in a browser with an empty workspace. They are not captures of an installed Windows build or an Android device.
