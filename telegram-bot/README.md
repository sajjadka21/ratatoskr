# ربات تلگرام راتاتوسک

لینک ویدیو یا آهنگ را بفرستید، کیفیت را انتخاب کنید، فایل را بگیرید. با yt-dlp کار می‌کند
(یوتیوب، اینستاگرام، توییتر، و بسیاری سایت‌های دیگر). لینک آهنگ اسپاتیفای از روی نام و خواننده
در یوتیوب پیدا می‌شود و به‌صورت صدا فرستاده می‌شود (فایل خود اسپاتیفای نیست).

## راه‌اندازی

۱. در تلگرام به `@BotFather` پیام بدهید، `/newbot` را بزنید و نام ربات را (مثلاً Ratatosk) انتخاب کنید. توکن را نگه دارید و جایی منتشر نکنید.

۲. ربات باید روی **سروری خارج از ایران** اجرا شود (تلگرام و یوتیوب از داخل ایران در دسترس نیستند).

۳. روی سرور:

```
git clone <این پروژه>  &&  cd telegram-bot
cp .env.example .env        # توکن را در TELEGRAM_BOT_TOKEN بگذارید
docker compose up -d --build
```

بدون Docker: `pip install -r requirements.txt` و نصب `ffmpeg`، سپس `python bot.py` با متغیرهای `.env`.

## تنظیمات مهم

- `ALLOWED_USER_IDS`: اگر خالی نباشد فقط این کاربران می‌توانند از ربات استفاده کنند (پیشنهاد می‌شود).
- `UPLOAD_LIMIT_MB`: پیش‌فرض ۴۹. تلگرام برای ربات‌ها حداکثر ۵۰ مگابایت اجازه می‌دهد. برای فایل تا ۲ گیگابایت،
  [Bot API محلی](https://github.com/tdlib/telegram-bot-api) اجرا کنید و `BOT_API_URL` را بدهید.
- `COOKIES_FILE`: فایل کوکیِ حسابی که خودِ شما کنترل می‌کنید، برای سایت‌هایی (مثل برخی پست‌های اینستاگرام)
  که بدون ورود باز نمی‌شوند. کوکی کاربران هرگز گرفته یا ذخیره نمی‌شود.

## نکته‌ها

- yt-dlp چون سایت‌ها مدام تغییر می‌کنند باید به‌روز بماند: هر چند هفته `docker compose build --pull --no-cache && docker compose up -d`.
- یوتیوب گاهی IP سرورهای ابری را محدود می‌کند؛ اگر دانلودها خطا دادند، `COOKIES_FILE` یا سرور دیگری امتحان کنید.
- ربات آدرس‌های داخل شبکه‌ی سرور (localhost، IP خصوصی) را رد می‌کند، هر کاربر هم هم‌زمان فقط یک دانلود دارد.
- مسئولیت محتوایی که دانلود می‌شود با استفاده‌کننده است؛ فقط چیزی را دانلود کنید که حق دانلودش را دارید.
