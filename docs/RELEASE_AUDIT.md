# Ratatoskr 1.0.2 — گزارش انتشار

نسخهٔ ویندوز و اندروید در [GitHub](https://github.com/sajjadka21/ratatoskr/releases/tag/v1.0.2) منتشر شده‌اند و لینک‌های مستقیم در [سایت فارسی](https://ratatoskr.hivenest.ir/fa/#download) و [انگلیسی](https://ratatoskr.hivenest.ir/#download) قرار دارند. انتشار در ۹ مهر ۱۴۰۵ انجام شد.

## اصلاحات

- نام محصول، نسخهٔ برنامه/نصب‌کننده/خط فرمان/اندروید و آدرس به‌روزرسانی هماهنگ شد؛ پروژهٔ محلی D:/project/download-manager نیز با حفظ تغییرات قبلی به 1.0.2 به‌روزرسانی شد.
- جمع‌آوری خروجی‌های تو در تو، امضای به‌روزرسانی، بررسی نسخه‌ها و چک‌سام‌ها اصلاح شد. انتشار فقط پس از موفقیت بررسی‌ها انجام می‌شود.
- APK به‌جای کلید debug با کلید ثابت تولید امضا می‌شود. امضا، شناسه، نسخه و debuggable نبودن قبل از انتشار بررسی می‌شوند.
- کتابخانه‌های اندروید به 0.18.1 ارتقا یافتند؛ پنج کتابخانهٔ داخلی WebP از منبع رسمی با NDK 27 برای صفحات حافظهٔ ۱۶ کیلوبایتی بازسازی شدند. SONAME، APIهای موجود و چیدمان باینری بررسی شد. شمارهٔ 1.0.1 پیش از انتشار لغو شد و تگ آن برای تاریخچه حفظ شد.
- مجوز اندروید GPL-3.0-only شد و مجوز دسکتاپ PolyForm Noncommercial باقی ماند؛ اعلان‌ها و کد منبع همان نسخه همراه خروجی‌اند.
- سایت روی Worker موجود Cloudflare به‌روزرسانی شد. دامنه و HTTPS فعال‌اند؛ برای IRNIC تغییر دیگری لازم نیست.

## بررسی انجام‌شده

تمام مراحل [ساخت انتشار](https://github.com/sajjadka21/ratatoskr/actions/runs/36805059276) موفق شدند: رابط، Rust، تست‌های اندروید، ساخت ویندوز/اندروید و انتشار. بررسی‌های امنیت و وابستگی‌های PR نیز موفق بودند.

پس از انتشار، هر هشت فایل عمومی دوباره دریافت شدند و اندازه و SHA-256 آن‌ها با GitHub تطبیق داده شد. امضای نصب‌کنندهٔ ویندوز مستقلاً با کلید عمومی داخل برنامه بررسی شد. فایل‌های اصلی نسخهٔ پرتابل ۶۴ بیتی‌اند و فایل فعال‌کنندهٔ حالت پرتابل همراهشان است.

APK: شناسه app.ratatoskr.android، نسخه 1.0.2، versionCode 3، اندروید ۱۰ به بالا، ABIهای arm64-v8a / armeabi-v7a / x86_64. امضای RSA 4096 و v2 معتبر است؛ اثرانگشت SHA-256 گواهی:

`4b1ca19c7645b36c951f793494506a125d3e01e41a2ed5336d5d49dceb85e476`

بررسی مستقلِ APK نهایی ۷۷۰ باینری ELF، شامل آرشیوهای داخلی، را پوشش داد. متن مجوز داخل APK و منبع WebP داخل بستهٔ کد منبع بررسی شدند؛ کلید خصوصی یا اطلاعات محلی SDK در بستهٔ منبع وجود ندارد.

سایت اصلی در مرورگر بررسی شد: لینک‌های چهار فایل دانلود و چک‌سام، متن فارسی، تاریخ شمسی و تفاوت مجوز دو نسخه صحیح‌اند؛ خطای کنسول مشاهده نشد. در عرض ۳۹۰ پیکسل، لینک‌های دانلود از عرض صفحه بیرون نمی‌زنند. رنگ روشن rgb(231,225,213) است و سفید خالص نیست.

## حدود بررسی

نصب/ارتقا و دانلود واقعی روی دستگاه فیزیکی ویندوز و اندروید هنوز مستقلاً آزموده نشده است. ویندوز گواهی ناشر Authenticode ندارد و ممکن است پیام ناشر ناشناس نشان دهد. امضای معتبرِ updater این مورد را حذف نمی‌کند. هشدار فعلی اندازهٔ بستهٔ رابط برنامه نیز باقی است؛ ساخت موفق است.

تصاویر سایت از رابط واقعی React پروژه در مرورگر با فهرست خالی‌اند؛ تصویر دستگاه فیزیکی یا دانلود ساختگی نیستند. محدودیت امکانات اندروید در سایت روشن شده است.

کلیدهای امضای موجود را برای انتشارهای بعدی حفظ و در جای امن پشتیبان بگیرید؛ آن‌ها در فایل‌های تحویلی قرار ندارند.
