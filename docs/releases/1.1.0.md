# Ratatoskr 1.1.0 — reliability preview

This preview adds a persistent Android download workspace and improves everyday desktop controls. It remains a prerelease until installation and real-transfer acceptance is recorded on physical devices. The previous stable release remains the automatic-update default.

## What's new

- Android queue and history survive app relaunch. Pause/resume keeps private workspaces and validates server identity before reusing file bytes.
- Separate Wi-Fi-only, unmetered and roaming preferences, shared concurrency limits and speed limits. Background continuation uses bounded system jobs; explicit force-stop is honored.
- Share a public Instagram link to choose video quality, audio, photos or album items. Optional quick download queues the link and returns you to the source app. Login-required/private posts are not promised.
- Generic public file links, friendly error states, notification open/share, and journaled publishing to Downloads/Pictures.
- Accountless desktop-to-Android QR link handoff. Install the Android app first, then scan a code from a download's context menu. The code contains the source link, not the downloaded file or an account session.
- Four brands with independent light/dark/system appearance. Light mode uses a warmer, softer background. Desktop settings have groups, search and keyboard navigation.
- Correct focus behavior in the add-download dialog and accessible names for compact sidebar controls.
- Recent browser heartbeat diagnostics and separate Chrome, Edge and Firefox packages. Store approval remains pending.
- Public-only DNS/socket guards for direct HTTP and a scoped native-media proxy. Credentials are not added to QR codes; backups explicitly disclose their unencrypted links and paths.

## Download choices

- Windows 10/11 x64: EXE installer, alternative MSI, or portable ZIP. Preserve the portable `data` folder during replacement.
- Android 10+: universal `Ratatoskr-android.apk`, or a smaller APK matching `arm64-v8a`, `armeabi-v7a` or `x86_64`. All release APKs use the same production certificate. APK signatures do not substitute for physical installation tests.
- Browser ZIPs are submission/manual-install packages, not approved marketplace listings.
- `SHA256SUMS.txt` covers every payload. Android corresponding source is included. Windows updater metadata/signature accompanies the installer.

## Known acceptance gates

Physical device checks remain open for upgrade continuity, live Instagram/CDN behavior through the native proxy, audio playback, Android 15 background continuation, QR scanning and interrupted MediaStore publication. See [acceptance checklist](https://github.com/sajjadka21/ratatoskr/blob/feature/mobile-reliability/docs/mobile-acceptance.md).

Windows currently has updater signing but no Authenticode publisher certificate. Windows may display an unknown-publisher warning. No claim of faster performance than competitors or exclusive features is made.

## فارسی

این نسخهٔ پیش‌انتشار، صف و تاریخچهٔ پایدار اندروید، ادامهٔ دانلود با کنترل هویت فایل، تنظیم مستقل Wi-Fi و اینترنت بدون محدودیت مصرف، انتخاب عکس و موارد آلبوم، استخراج صدا و دانلود لینک فایل عمومی را اضافه می‌کند.

برای اینستاگرام، لینک عمومی را از منوی اشتراک‌گذاری به Ratatoskr بفرست. حالت سریع لینک را در صف می‌گذارد و به برنامهٔ قبلی برمی‌گردد. دانلود محتوای خصوصی یا نیازمند ورود تضمین نمی‌شود.

در ویندوز، از منوی دانلود «ارسال لینک به گوشی» را انتخاب و QR را با گوشی اسکن کن. این قابلیت بدون حساب است و فقط لینک را منتقل می‌کند. تم روشن ملایم‌تر شده و تنظیمات جست‌وجو و گروه‌بندی دارند.

فایل APK عمومی برای بیشتر کاربران مناسب است؛ فایل مخصوص معماری می‌تواند کوچک‌تر باشد. بسته‌های افزونه هنوز تأیید فروشگاه ندارند. نصب و دانلود واقعی روی دستگاه فیزیکی، ادامهٔ کار پس از محدودیت‌های اندروید و سازگاری موتور رسانه هنوز باید تأیید شوند؛ بنابراین این نسخه جای نسخهٔ پایدار در به‌روزرسان خودکار قرار نمی‌گیرد.
