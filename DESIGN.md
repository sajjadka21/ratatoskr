# Ratatoskr landing direction

The page introduces a desktop download manager whose approved identity pairs a gold squirrel with Norse botanical engraving. The first version honestly presents an app in development, while release links remain configurable.

Palette: obsidian #0A0E11, raised charcoal #151A20, antique gold #EAC483, parchment #F2EDE3, quiet slate #A7B0BA, decorative border #34302A.

Type: outlined approved-style wordmark; Palatino/Book Antiqua for editorial display headings; a system sans for interface, body copy and controls. No external font requests.

Structure: a generous product-led hero, one framed application preview, a restrained introduction, an interactive four-theme gallery, a truthful release section, expandable answers and a compact footer.

Alignment: left-aligned copy on desktop, compact left-aligned mobile layout. Ornament is concentrated behind the hero frame and theme gallery. The rest of the page uses clear space and thin functional separators.

Review against brief: the ornate squirrel and four approved theme palettes drive the visual, rather than generic SaaS gradients, statistics or repeated feature cards. Never claim speed, privacy, license, browser integration or resumability until confirmed. App previews are labeled design previews. The app is under development and no release version or download URL is invented.

Interaction: theme tabs switch preview/pattern/name/description, with keyboard navigation and state persistence; FAQ uses native details; release actions appear only when real links are configured. No ornamental perpetual animation.
